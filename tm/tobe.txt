# ThinkMech Solutions Website Development Document

## Objective

Develop a modern, responsive, SEO-friendly corporate website for **ThinkMech Solutions**, an HVAC engineering company. The design should be premium, fast, and professional, similar to leading engineering companies.

The website should communicate that ThinkMech is a **Single Point of Contact (SPOC)** for complete HVAC engineering solutions, from design to maintenance.

# Developer Notes

1. Avoid duplicate sections currently present in the provided content.
2. Create reusable components for Hero, CTA, Footer, Contact Banner, and Service Cards.
3. Make every service page SEO optimized with unique H1, meta title, and meta description.
4. Use image optimization (WebP), lazy loading, and responsive layouts.
5. Add schema markup for Organization, Local Business, Services, and FAQs.
6. Optimize for Core Web Vitals (LCP, CLS, INP).
7. Include floating WhatsApp and "Get a Quote" buttons.
8. Ensure all contact forms send inquiries via email and store submissions in the admin panel or database.
9. Make the CMS modular so future services, projects, clients, testimonials, and blogs can be added without code changes.
10. Preserve the technical HVAC content from the provided document while rewriting it into concise, professional website copy and eliminating repeated sections.
